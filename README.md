# 1:- Client Signup
Name: The client must enter their name.

Email: The client must provide a valid email address.

Password: The password must contain at least one digit and at least one uppercase letter.

Organization:

If the client is posting a project for personal reasons, they should select "Personal."

If posting on behalf of an organization, they must enter the organization's name.

# Creating Bank Account
The client must enter their bank account number.

A unique transaction ID must be generated for payments to freelancers.

# 2:- Freelancer Signup
Name: The freelancer must enter their name.

Email: The freelancer must provide a valid email address.

Password: The password must include at least one digit and at least one uppercase letter.

Experience: The freelancer should enter their experience in years. If they have none, they can enter 0.

Rating: Freelancers can optionally enter their rating from any coding platform.

Skills: Freelancers can list their skills (e.g., programming languages, frameworks, tools), separated by spaces.

# Profile Creation
A description of their background

Details about projects they've worked on

Skills they possess

Their experience level

Educational qualifications

Any other relevant information related to their work or education

# Creating Bank Account

The freelancer must enter their bank account number.

A unique transaction ID should be generated for receiving payments.

# Features that Client have in the Website
1:- HomePage:- On  these page client can see all the projects which are projected by him and other clients on the platform

2:- Pending Request:-  On these page   client can see all the request that freelancer has done on the project that are posted by him on the portal and here client can accept or reject the project by seeing the freelancer profile description and skills

3:- Client Ongoing Project:- On these page client can see all the ongoing project on which currently freelancer is working

4:- Client Completed Project:- On these page client can see that project which are completed and the payment of that project has also done

5:- Post Job:- On these page client can post the project client has to give the Title of the project, Description of the project and the Budget of the Project

6:- Add money to wallet:- On these page client has to fill the account number and the money will be debited from the bank and will credited to the client wallet

7:- Add money to bank:- On these page client has to fill the account number and the money will be debited from the wallet and will credited to the client bank

8:- Client Name:- Name of the logged in Client will be displayed

# Feature that Freelancer will have
1:- Optimize Resume and Letter:- On these page freelancer can upload his resume and cover letter and then he has to paste the job or project description and after clicking on Analyze button he will get the which terminology and keywords are missing in the resume or letter according to the job description pasted

2:- User Completed Project:- On these page the project which are completed by freelancer and the payment is also received that project are shown here

3:- User Ongoing Project:-  On these page the project which are accepted by the client and currently the freelancer is working on the project that project are shown on these page

4:- Add Money to Wallet:- On these page freelancer has to fill the account number and the money will be debited from the bank and will credited to the freelancer wallet

5:-  Add money to bank:- On these page freelancer has to fill the account number and the money will be debited from the wallet and will credited to the client bank

6:- Check Uniqueid:- On clicking freelancer can his transaction id which he has to give to the client so he can transfer the project amount to the freelancer’s wallet

7:- User Name:- Name of the logged in freelancer will be displayed

# Start Communication 
These features are used by both the client and the freelancer when the request for the particular project is accepted by the freelancer then for discussing anything about the project client and freelancer can use these feature like discussing the project milestone,sharing the transaction id for the payment and these feature is individually applicable for client and freelancer for each project

# Make Payment
Only client can use these feature to make the payment after the project completion in these client has to enter it’s transaction id,freelancer's transaction id and the amount which has to paid for the project after the completion of the payment the project will be deleted from Ongoing Project and move to be the Completed Project for both client and freelancer
